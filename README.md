# Strawbr — website

Site vitrine de Strawbr SAS, servi par GitHub Pages sur https://strawbr.com.

Fichiers HTML/CSS statiques, sans build : chaque push sur `main` met le site à jour.

- `index.html` : page d'accueil
- `legal/` : mentions légales (Legal notice)
- `privacy/` : politique de confidentialité, à donner à Google Play et à l'App Store → https://strawbr.com/privacy/
- `assets/` : styles et logo
- `CNAME` : domaine personnalisé pour GitHub Pages

Aperçu local : `npx serve .` puis http://localhost:3000.
